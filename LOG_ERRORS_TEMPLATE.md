## PREVENTION ACTIVE THRESHOLD

```
MAX_ACTIVE_PATTERNS : 20  (configurable in STABLE · QC_MAX_ACTIVE_PATTERNS)

When |PREVENTION ACTIVE| > MAX_ACTIVE_PATTERNS:
→ Trigger macro-pattern consolidation (SOP-QC Consolidation procedure)
→ Group related low-severity patterns into a single macro-rule
→ Condensed notes merged → one macro-prevention note per cluster
→ Individual notes remain in RESOLVED ERRORS (never deleted)
→ Update QC STATS: COMPRESSED_PATTERNS updated

This prevents PREVENTION ACTIVE from becoming a source of cognitive noise.
Below threshold: no consolidation triggered.

ABSTRACTION CONSTRAINT: macro-notes must retain domain-specific signals.
A macro that could apply to any domain is invalid — refine or skip consolidation.
Test: would the macro have caught each individual error it replaces?
```

## COMPRESSION PROTOCOL

```
TRIGGER: error STATUS = resolved AND
         (severity = low AND age_resolved > 60 days) OR
         (severity = medium AND age_resolved > 90 days)

ACTION:
① Condense PREVENTION field to one line
② Add condensed note to PREVENTION ACTIVE section with [SEVERITY] tag
③ Move full entry from ACTIVE ERRORS → RESOLVED ERRORS
④ Full entry never deleted — accessible on demand and on recurrence

ON RECURRENCE (error reappears after compression):
① Detect via PREVENTION ACTIVE scan match
② Fetch full entry from RESOLVED ERRORS
③ STATUS: resolved → STATUS: recurring
④ Increment recurrence counter
⑤ Elevate SEVERITY by one level (low→medium · medium→high · high→critical)
⑥ Move condensed note to [critical] or [high] band in PREVENTION ACTIVE
⑦ Restore full entry to ACTIVE ERRORS

NEVER COMPRESS:
→ SEVERITY: critical (never · always full active scan)
→ SEVERITY: high (never compressed)
→ STATUS: recurring (always full active)
→ STATUS: conflict_unresolved (surface to user first)
→ Domain errors with DOMAIN_CRITICAL flag

SUPERSEDED STATUS:
→ When a pattern is overridden by a higher-priority conflicting pattern:
   · STATUS: resolved → superseded
   · Condensed note removed from PREVENTION ACTIVE
   · Full entry remains in RESOLVED ERRORS (never deleted)
   · Superseding pattern documented in entry: SUPERSEDED_BY: [ID]
```
